# Install

1. Install Node.js 22 or later and run `node --version` to check it.
2. Download `picat.js` and `picat.wasm` from the same [GitHub release](https://github.com/r33drichards/picat-inventory-planner/releases).
3. Put the files in the same directory. The JavaScript launcher loads the companion
   WebAssembly file and runs the embedded inventory program.

Continue with [Sort your first inventory](../tutorials/first-plan.md).
